# Hardware and Software Requirements

## Software Requirements

### Operating System
Cross-Platform (Windows, MacOS, Linux)

### Runtime & Package Managers
- **Node.js**: Version 18.x or higher
- **npm**: Version 9.x or higher (comes with Node.js)

### Database
- **MongoDB**: Version 6.0 or higher (NoSQL Database)
- **Mongoose**: Version 9.x (Object Data Modeling for Node.js)

### Development Tools
- **Express.js**: Fast, unopinionated, minimalist web framework for Node.js
- **Vanilla JavaScript**: For client-side logic and backend development
- **CSS3**: For custom styling and responsive design
- **HTML5**: For semantic web structure
- **JWT (JSON Web Token)**: For secure user authentication and session management
- **BcryptJS**: For password hashing and security

---

## Hardware Requirements

### Production/Development Server
- **Processor**: Dual-core or Quad-core CPU
- **Memory**: 8 GB RAM or more
- **Disk Space**: 1 GB available space (excluding database storage)
- **Network**: Stable internet connection with adequate bandwidth
